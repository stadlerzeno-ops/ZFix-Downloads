# ZFix Autoradio

Apps für die Autoradios im Opel Agila und im Fiat Ducato. Der **ZFix Launcher** lädt Updates von hier:
ZFix-Menü (lange auf „ZFIX“ drücken) > **Update suchen**. Das Auto braucht dafür nur Internet (WLAN oder Handy-Hotspot).

| Datei | Inhalt |
|---|---|
| `versionen.json` | Liste der aktuellen Versionen (Paket, versionCode, Datei, SHA-256) |
| `ZFix-Launcher-*.apk` | Startbildschirm |
| `ZFix-DAB-*.apk` | DAB+ mit dem USB-Stick |
| `launcher/` | Quellcode des Launchers, Bauanleitung in `launcher/README.md` |

Erstinstallation ohne Mac: APK auf einen USB-Stick kopieren und im Dateimanager des Radios öffnen.
